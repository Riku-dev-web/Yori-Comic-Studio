YORI COMIC STUDIO - VERSION 1.0

WINDOWS 10/11
1. Installer Python 3.11 ou 3.12 depuis python.org (cocher Add Python to PATH).
2. Extraire le ZIP dans un dossier.
3. Double-cliquer BUILD_WINDOWS.bat.
4. Attendre la compilation puis ouvrir dist\YoriComicStudio.exe.

UTILISATION
- Choisir un outil à gauche, dessiner sur la page blanche.
- Double-cliquer sur les textes/bulles pour les modifier.
- Sélectionner un objet pour le déplacer ou le supprimer.
- Ajouter des pages, sauvegarder en .ycomic, exporter PNG ou PDF.
- Les images insérées sont liées à leur chemin d'origine : ne pas les déplacer après sauvegarde.

NOTE : le programme .exe est compilé sur Windows. Les images du projet doivent rester accessibles sur l'ordinateur.
